## ETS2LA Website
This repository contains the code for our publicly available website: https://ets2la.com.

## AI Use Disclaimer
Unlike with the main ETS2LA repository, I used AI to assist in writing some of the **code** (not *content*) for this website. The code is most certainly not clean, nor is it likely how the website *should* be coded, however this was fast and it works. I will welcome all contributions to cleanup the code, but please do note that in this case it would have to be an improvement, meaning *human made*.

I don't claim this website as my own work, and I will not take credit for code I have not written, I do take *responsibility* for the code I have reviewed.

## Contributing
AI use guidelines are not as strict here as on the main repository. You can use AI and agentic tools in the coding parts of your contributions, but please do not use AI for **content** contributions. All content should be human written, and if you do use AI for code, please make sure to review it, and ensure it doesn't edit 20 different files across the repository. I will be closing all PRs that change insane amounts of lines for simple changes.
