## I want to block the use of ETS2LA in/with my VTC/Program
That's totally fair! We provide two ways for VTC owners to detect ETS2LA. 
One of these is via the log files, just look for any log containing `ets2la` 
and you'll be golden. We also provide a more reliable way through the plugin's 
virtual memory. For more information on how to read this check it's 
[GitHub page](https://github.com/ETS2LA/plugin), the first virtual memory entry 
listed in the readme is used to detect ETS2LA, and how much it's being used.

If you want to display a notice inside ETS2LA, contact us via Discord to provide
us with a way to detect if you app is open. Anything goes, so long as it doesn't
change between updates.
