# Installation
### Installation Steps
1. Download the latest installer from https://ets2la.com/download. See the webpage for instructions on which file to download.
2. Run the installer and follow the on-screen instructions.
3. **Follow the ETS2LA onboarding process, and install the SDK!**
4. Open the game and drive to a road.
5. Press the `SET` keybind to enable ETS2LA.

If you have any issues, please see the FAQ section on this website.
