# Getting Started

> [!NOTE]
> This guide is also available as a 4 minute [video walkthrough](https://youtu.be/My-mk4lXr00?si=c2c2fJbJFGPr2uDo).

## 1. Install ETS2LA

Download the installer for your platform from the [download page](#/download),
then run it and follow the prompts.

| Platform | File | Requirements |
| --- | --- | --- |
| Windows | `ETS2LA-win-*.msi` | Included |
| Linux | `ETS2LA-linux-*.AppImage` | GLIBC 2.43 |

> [!TIP]
> ETS2LA is version specific, make sure you're on a game version listed in the
> latest release notes.

## 2. Follow the ETS2LA onboarding

When you first launch ETS2LA, it will guide you through the onboarding process.
This onboarding process contains everything you need to get started.

## 3. Use Your Keybinds

Once you've got some plugins enabled, you can enable their features by using 
keybinds, by default these are the following:
| Action | Keybind |
| --- | --- |
| RES / Increase | `Up Arrow` |
| SET / Decrease | `Down Arrow` |
| MODE / Cancel | `Left Arrow` |
| Next / Confirm | `Right Arrow` |

The TLDR is that you can use the **RES** and **SET** buttons to enable, and 
the **MODE** button to disable driving assistance.

## Troubleshooting

If something isn't working, the [FAQ](#/help/faq) covers the most common
